HWSonnet liest direkt aus /proc, /sys und nativen Linux-APIs. Kein Umweg, kein Raten — rohe Daten direkt vom Kernel.

CPU

CPU-Uberwachung

Echtzeit-Auslastung pro Kern, Taktfrequenz, Temperatur und vollstandige Cache-Hierarchie — uber psutil und /proc/cpuinfo.

GPU

GPU-Unterstutzung

NVIDIA via nvidia-smi, AMD via /sys/class/drm, Intel-Erkennung. VRAM, Auslastung, Temperatur und Leistungsaufnahme.

RAM

Arbeitsspeicher

Echtzeit-RAM- und Swap-Auslastung mit Live-Charts. Typ, Geschwindigkeit und Steckplatzinformationen via dmidecode.

HDD

Speicher & SMART

SSD-, HDD- und NVMe-Erkennung mit lsblk. SMART-Gesundheitsstatus, Temperatur und Live-Lese-/Schreibgeschwindigkeit.

NET

Netzwerkschnittstellen

Alle Netzwerkadapter mit IPv4/IPv6, WLAN-SSID und Signalstarke sowie Echtzeit-Bandbreitencharts fur Upload und Download.

TMP

Hardware-Sensoren

Temperaturen, Lufterdrehzahlen und Akkustatus via lm_sensors und /sys/class/hwmon. Farbkodierte Warnungen.

SYS

Systeminformationen

Betriebssystem, Kernel, Desktop-Umgebung, Shell, Laufzeit, Mainboard, BIOS sowie installierte Pakete (pacman und Flatpak).

EXP

Berichte exportieren

Vollstandige Hardware-Berichte als JSON, TXT oder PDF exportieren. Ideal fur Dokumentation und Support.

CHT

Eigene Charts

Glatte Catmull-Rom-Spline-Kurven, gezeichnet mit QPainter. Keine externe Chart-Bibliothek erforderlich.

Erste Schritte

HWSonnet installieren

Wahle deine bevorzugte Installationsmethode. Das AUR-Paket lost alle Abhangigkeiten automatisch auf.

AUR — Empfohlen yay

Mit einem beliebigen AUR-Helfer installieren. Alle Abhangigkeiten werden automatisch aufgelost.

# Installation via yay
yay -S hwsonnet

# Oder mit paru
paru -S hwsonnet
# Starten
hwsonnet

Manuell git

Repository klonen und das Installationsskript ausfuhren — erstellt einen Desktop-Eintrag und einen Starter.

git clone https://github.com/Varionetzwerk/hwsonnet
cd hwsonnet
./install.sh
# Direkt starten
python main.py

Abhangigkeiten pacman

Kern-Pakete und optionale Erweiterungen fur vollstandige Funktionalitat.

# Erforderlich
sudo pacman -S python python-pyqt6 python-psutil

# Optional (mehr Funktionen)
sudo pacman -S lm_sensors smartmontools
sudo pacman -S mesa-utils nvidia-utils
