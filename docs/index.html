What's Inside

Everything you need to know
about your hardware

HWSonnet reads directly from /proc, /sys and native Linux APIs. No bloat, no guessing — raw data from the kernel.

⬡

CPU Monitoring

Live per-core usage bars, frequency tracking, temperature gauges and full cache hierarchy — using psutil and /proc/cpuinfo.

▦

GPU Support

NVIDIA via nvidia-smi, AMD via /sys/class/drm, Intel GPU detection. VRAM usage, utilization, temperature and power draw.

≡

Memory Details

Real-time RAM and swap usage with live charts. RAM type, speed, and slot info via dmidecode.

⊟

Storage & SMART

SSD, HDD and NVMe detection with lsblk. SMART health status, temperature, live read/write speed per device.

⊕

Network Interfaces

All network adapters with IPv4/IPv6, WiFi SSID and signal, and real-time upload/download bandwidth charts.

◎

Hardware Sensors

Temperatures, fan RPM and battery status via lm_sensors and /sys/class/hwmon. Color-coded critical warnings.

⚙

System Information

OS, kernel, desktop environment, shell, uptime, mainboard, BIOS info and installed package counts for pacman and Flatpak.

📤

Export Reports

Export complete hardware reports as JSON, TXT or PDF. Perfect for system documentation or support tickets.

🎨

Custom Charts

Smooth Catmull-Rom spline charts drawn with QPainter. No external chart library dependency.

Get Started

Install HWSonnet

Choose your preferred installation method. The AUR package handles all dependencies automatically.

AUR (Recommended) yay

Install with any AUR helper. All dependencies are resolved automatically. 

# Install via yay
yay -S hwsonnet

# Or with paru
paru -S hwsonnet
# Launch
hwsonnet

Manual Install git

Clone and run the install script — creates a desktop entry and launcher. 

git clone https://github.com/Varionetzwerk/hwsonnet
cd hwsonnet
./install.sh
# Run directly
python main.py

Dependencies pacman

Core dependencies + optional packages for full feature access. 

# Required
sudo pacman -S python python-pyqt6 python-psutil

# Optional (enables more features)
sudo pacman -S lm_sensors smartmontools
sudo pacman -S mesa-utils nvidia-utils
